ORDER INTELLIGENCE HUB TABLEAU

**Order Intelligence Hub Tableau** is a Tableau-based Business Intelligence project that analyzes food delivery data using Microsoft Excel. It integrates order, customer, restaurant, payment, product, cuisine, and delivery partner information into interactive dashboards. The project provides valuable insights into order performance, customer behavior, restaurant efficiency, revenue trends, and delivery operations, helping businesses make data-driven decisions and improve overall business performance.

---

🚀 Features

- Order and revenue analytics
- Customer behavior and demographic insights
- Restaurant performance monitoring
- Delivery partner performance analysis
- Payment method analysis
- Cuisine and product popularity tracking
- Interactive dashboards with KPI reporting
- Dynamic filtering using Tableau filters and dashboard actions

🧪 How It Works

- Imports food delivery datasets from Microsoft Excel into Tableau.
- Prepares and organizes data for analysis.
- Creates calculated fields to measure business performance.
- Develops interactive charts and visualizations.
- Combines multiple worksheets into comprehensive dashboards.
- Uses filters and dashboard actions for dynamic data exploration.
